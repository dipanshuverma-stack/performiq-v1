# PerformIQ Design System

## Principles

1. Desktop-first
2. Consistency over creativity
3. Reuse before creating
4. One purpose per component
5. Data first, decoration second
6. Accessible by default
7. Responsive without redesign
8. Dark and Light theme compatible
